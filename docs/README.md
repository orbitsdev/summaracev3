# SummaRace v3 documents

The documents are HTML pages with diagrams. GitHub shows HTML as code, so open them in a browser:

- download or clone the repo and open `docs/index.html`, or
- turn on GitHub Pages for the `docs/` folder.

**All in one file:** [SummaRace-v3-Handover-Package.pdf](SummaRace-v3-Handover-Package.pdf) (GitHub shows PDFs) or `SummaRace-v3-Handover-Package.html` (self-contained, open in a browser). Both include every document plus the handover list of known open items and the answer key.

| Page | What it covers |
|---|---|
| [index.html](index.html) | Contents |
| [01-prd.html](01-prd.html) | Product requirements: features, scoring, open items |
| [02-trd.html](02-trd.html) | Technical requirements: stack, architecture, race, summary checker |
| [03-app-flow.html](03-app-flow.html) | Screen flow, race loop, unlock rules, Back button |
| [04-design-brief.html](04-design-brief.html) | Colours, fonts, components, screenshots |
| [05-data-schema.html](05-data-schema.html) | stories.js, localStorage, CSV format |
| [06-implementation-plan.html](06-implementation-plan.html) | What was built, by phase |
| [07-system-design.html](07-system-design.html) | System context, components, data flow, voice pipeline, race state machine, failure handling |
| [08-requirements.html](08-requirements.html) | What a laptop, PC or phone needs to run the game, setup steps, controls, troubleshooting |
| [assets.html](assets.html) | Every asset with source, author and license |
| [answer-key.html](answer-key.html) | Right answers for all 30 stories |

They describe version 1.3.6 (versionCode 17).
