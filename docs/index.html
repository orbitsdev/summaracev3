Version 1.3.6 (versionCode 17) · Android app com.summarace.app · written 2026-11-05

SummaRace is an offline reading game for Grade 4 learners: read a story, race to collect its parts, put them in order, and sum it up in 2–3 sentences. These documents describe the game as it is built today.

All in one file: SummaRace-v3-Documentation.html (works offline) or SummaRace-v3-Documentation.pdf. Both hold every document below plus the handover list of known open items and the answer key.
