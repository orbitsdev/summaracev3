App Flow Document

SummaRace v3 · version 1.3.6

1Overview

This document shows what happens when someone taps, and which screen comes next. It maps the main journeys through the game, from opening the app to finishing a level and exporting records.

2Key user journeys

First play

Open app → PLAY → type name and section → World map → Level 1 → read, race, order, summarise → Results → Next.

Returning learner

PLAY → tap the learner's name under "Or continue as" → the map scrolls to their open level → Play.

Replay for more stars

Map → tap a finished level → Play again. Best stars and best score are kept.

Teacher collects results

PLAY → Teacher records (or Settings → Teacher records) → Copy, Download or Share CSV.

Stop mid-level

Settings or the Back button → Quit this story → World map. The unfinished level is not recorded.

Change player

Settings → Change player (or tap the name chip) → "Who is playing?".

5Race flow

6Unlock rules

  • A new profile starts with Level 1 open.
  • Finishing level n (any score) opens level n + 1. Levels open strictly one by one.
  • The session bar on the map groups levels in threes (session 1 = levels 1–3). A session chip is locked until its first level is open.
  • Level n belongs to world ⌊(n − 1) ÷ 6⌋: levels 1–6 Sunny Meadow, 7–12 River Bend, 13–18 Story Town, 19–24 Palm Beach, 25–30 Summit Peak. The world sets the race scenery and the screen backdrop.
