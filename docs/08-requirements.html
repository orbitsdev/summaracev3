System requirements

System Requirements and Setup

SummaRace v3 · version 1.3.6 (versionCode 17) · what a laptop, PC or phone needs to run the game, and how to set it up

1Overview

SummaRace is made for Android phones, but the game itself is a web page, so it also runs on a laptop or desktop PC in a normal web browser. This document lists what each kind of device needs and gives the steps to get the game running.

Play on a laptop or PC

Open the game in Chrome or Edge. No install and no internet needed. Good for demos, panel defences and teachers checking the stories. See sections 2–4.

Play on an Android phone

Install the APK. This is how learners use it in class. See section 5.

Build a new version

For a developer changing the game: Android Studio, JDK 17 and the signing key. See section 6.

3Install guide: play on a Windows laptop or PC

Each step says what to do, where to do it, the command to type (if any) and what you should see when it worked. Option A needs only a browser. Option B also needs Python.

  1. Check the browser Where: Google Chrome or Microsoft Edge (Edge is already on every Windows 10/11 PC). Type in the address bar: chrome://settings/help (Chrome) or edge://settings/help (Edge), then press Enter. You should see: "Chrome is up to date" or "Microsoft Edge is up to date" and a version number of 80 or higher. If Chrome is missing: download it from google.com/chrome.
  2. Turn on graphics acceleration (needed for the 3D race) Type in the address bar: chrome://settings/system or edge://settings/system Do: switch on Use graphics acceleration when available and click Relaunch if it asks.
  3. Download the game Where: in the browser, open github.com/orbitsdev/summaracev3/archive/refs/heads/main.zip (or open github.com/orbitsdev/summaracev3 and click the green Code button → Download ZIP). You should see: summaracev3-main.zip in your Downloads folder.
  4. Unzip it Where: File Explorer → Downloads. Right-click summaracev3-main.zip → Extract All… → choose a folder such as C:\Users\<you>\Documents → Extract. You should see: a folder Documents\summaracev3-main. The game itself is in summaracev3-main\app\src\main\assets\www (it contains index.html, stories.js and the models, voice and fonts folders).

Option A: open the game straight from the folder (no install)

  1. Open the game Where: File Explorer → summaracev3-main\app\src\main\assets\www Do: right-click index.html → Open with → Google Chrome or Microsoft Edge. You should see: the SummaRace title screen with Teacher Mira and a green PLAY button. The address bar starts with file:///C:/.
  2. Go full screen with F11 (press F11 again to leave), then click PLAY.

Option B: run it from a local web server (for developers)

  1. Install Python 3 Download: python.org/downloads/windows → latest Python 3 Windows installer (64-bit). Do: run the installer and tick "Add python.exe to PATH" on the first screen, then Install Now.
  2. Check that Python works Where: press the Windows key, type cmd, press Enter (Command Prompt opens). Type: python --version You should see: Python 3.x.x. If it says "not recognized", see section 7.
  3. Open a Command Prompt inside the game folder Where: File Explorer → summaracev3-main\app\src\main\assets\www. Click the address bar at the top, type cmd and press Enter. You should see: a Command Prompt whose line ends with ...\app\src\main\assets\www>
  4. Start the server Type: python -m http.server 8000 You should see: a line like Serving HTTP on :: port 8000 .... Leave this window open while playing.
  5. Open the game Where: Chrome or Edge address bar. Type: http://localhost:8000 You should see: the title screen. To stop the server, click the Command Prompt window and press Ctrl + C, or close it.

Phone-sized view (optional)

In Chrome or Edge press F12, click the phone-and-tablet icon at the top left of the panel (or press Ctrl + Shift + M), pick a phone such as iPhone 12 Pro (390 × 844), then press F5 to reload.

Differences from the phone app

  • Saved progress and records stay in that browser on that computer. Another browser, a private window, or "clear browsing data" starts empty. Option A and option B also keep separate records.
  • Records: use Download CSV (saved to the browser's Downloads folder) or Copy CSV. Share may not be offered on a PC.
  • Voice: Mira's recorded clips play as normal. The few lines without a clip use the computer's built-in voice.
  • Exit game is hidden; close the browser tab instead.
  • The browser may block sound until the first click. This is normal; sound starts after PLAY.

Install the APK

  1. Copy the APK to the phone: connect the phone with a USB cable, choose File transfer on the phone, then in File Explorer drag app-release.apk into the phone's Download folder. (Google Drive or a messaging app also works.)
  2. Open it on the phone: Files app → Downloads → tap app-release.apk. When Android asks, allow Install unknown apps for the Files app, go back and tap Install.
  3. You should see: "App installed" and a SummaRace icon on the home screen. Open it and play the first page to check it works.
  4. If an old SummaRace 1.2.0 test build is installed, uninstall it first: it was signed with a different key.

  2. Install Android Studio Download: developer.android.com/studio → run the installer with the default options. First start: the Setup Wizard opens. Choose Standard, accept the licences and click Finish. It downloads the Android SDK (this takes a while).
  3. Install Android 15 (API 35) Where: Android Studio → Tools → SDK Manager (on the Welcome screen: More Actions → SDK Manager) → tab SDK Platforms. Do: tick Android 15.0 ("VanillaIceCream") API 35 → Apply → OK.
  4. Open the project Where: Android Studio → File → Open (Welcome screen: Open) → select the project folder from step 1 → OK. Choose Trust Project if asked. Then File → Sync Project with Gradle Files.
  5. Raise the version number Where: Project panel → app → build.gradle (Module :app). Change: versionCode 17 → versionCode 18 and versionName '1.3.6' → the new version, e.g. '1.3.7'. Then click Sync Now at the top of the file.
  6. Test build (optional, not for learners) Where: Build → Build App Bundle(s) / APK(s) → Build APK(s). You should see: a pop-up "APK(s) generated successfully" with a locate link. The file is app\build\outputs\apk\debug\app-debug.apk. A debug APK cannot update the release app on the phones.
  7. Release build, signed with the SummaRace key Where: Build → Generate Signed App Bundle or APK… → choose APK → Next. Key store path: Choose existing… → the .jks file in Documents\SummaRace-signing → enter the key store password, key alias and key password → Next. Build variant: release → Create (Finish). You should see: "APK(s) generated successfully" → click locate. The file is app\release\app-release.apk in the project folder.
  8. Install it on a phone as in section 5, then play one full level before handing it out.

Never commit the keystore, *.jks, *.keystore or local.properties. The repository is public. A build signed with any other key cannot update the app already on the phones.

Create a new signing key (only when the current key is not available)

Read this first. Android only lets an app update itself when the new APK is signed with the same key. An APK signed with a new key cannot update SummaRace already on a phone: the old app must be uninstalled first, and uninstalling deletes every learner's progress and records on that phone. Before switching keys, the teacher must Download CSV from Teacher records on every phone.

  1. Make a folder for the key, outside the project folder Where: File Explorer → Documents → right-click → New → Folder → name it SummaRace-signing. Why: anything inside the project folder can end up on GitHub by mistake.
  2. Easiest way: create the key in Android Studio Where: Build → Generate Signed App Bundle or APK… → APK → Next → under Key store path click Create new… Fill in: Key store path C:\Users\<you>\Documents\SummaRace-signing\summarace-release.jks, a password (twice), Alias summarace, a key password, Validity 25 years, and at least one name field (for example Organization) → OK. Then: continue with step 7 above (release → Create).
  3. Or create it with a command (keytool) Where: Command Prompt opened in Documents\SummaRace-signing (address bar → cmd → Enter). Type (one line; keytool comes with Android Studio): 
    "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore summarace-release.jks -alias summarace -keyalg RSA -keysize 2048 -validity 10000
    Answer: the password questions and the name questions, then type yes to confirm. You should see: [Storing summarace-release.jks], and the file summarace-release.jks in the folder.
  4. Write down and back up Keep: the .jks file, the key store password, the alias (summarace) and the key password. Back up: copy the .jks to a USB drive and to private cloud storage. If it is lost again, every phone will need another uninstall.
  5. Never commit it Do not put *.jks, *.keystore, passwords or local.properties in the project folder or on GitHub; the repository is public. The project's build.gradle has no signing settings, so nothing in the code needs to change: the key is picked in the step 7 wizard each time.

7Troubleshooting

ProblemFix
Blank or white pageUse Chrome or Edge, and check the whole www folder was copied (not only index.html). If it still fails, use option B.
"The race could not start"WebGL is off. In Chrome or Edge, turn on Settings → System → Use graphics acceleration, then restart the browser.
The race is slow or jerkyClose other tabs and plug in the laptop. The game switches to a lighter mode by itself below 22 frames per second.
No soundClick once on the page, check the volume, and check the Voice, Sound and Music switches in Settings.
Progress is goneThe browser's data was cleared, or a different browser, private window or option (A or B) is in use.
python is not recognisedInstall Python 3 from python.org and tick Add python.exe to PATH, or try py -m http.server 8000.
Port 8000 is busyUse another number, for example python -m http.server 8080 and open http://localhost:8080.
